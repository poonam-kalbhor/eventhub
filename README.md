
# EventHub -  Event Discovery

EventHub is an event discovery website built using Next.js, TypeScript, and Tailwind CSS , Primereact.

Users can explore upcoming events, search events, apply filters, and save their favourite events.

## Features

- Browse upcoming events.
- Search events by title, location, and tags.
- Filter events by category and month.
- Filter events by maximum price.
- Show free events only.
- Save and remove favourite events.
- View saved events in a sidebar drawer.
- Light and dark theme support.
- Responsive design for mobile, tablet, and desktop.
- Animations using Framer Motion.

## Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- PrimeReact
- Framer Motion
- next-themes

## Installation

Clone the repository:

```bash
git clone 
```

Go to the project folder:

```bash
cd event-dashboard
```

Install dependencies:

```bash
npm install
```

## Run the Project

Start the development server:

```bash
npm run dev
```

Open the following URL in your browser:

```text
http://localhost:3000
```
